# 01 - 项目结构总览

> 版本：2026-11-18

## 一、顶层结构

```text
log-anomaly-detection/
├── backend/
│   ├── log-anomaly-detection/     # Spring Boot 后端（Maven 模块）
│   └── detection-service/         # Python 数据生成 + FastAPI 桩
├── data/                          # 本地数据集（gitignore）
│   ├── *.csv                      # CIC-IDS2018 原始数据
│   └── cleaned/                   # clean_data.py 生成的数据
├── sql/
│   ├── init.sql                   # 建库、建表、初始化 admin
│   └── reset_table.sql            # 重置三张业务表（保留 user）
├── doc/
│   └── design/                    # 设计文档
├── README.md                      # 项目概述与快速开始
└── CLAUDE.md                      # 本地开发说明（被 .git/info/exclude 忽略）
```

说明：

- **没有 `frontend/` 目录**，前端尚未创建；
- `backend/` 下有两个独立模块，后端模块的路径是嵌套的 `backend/log-anomaly-detection/`；
- `data/` 被根 `.gitignore` 忽略，新克隆的仓库没有数据文件。

## 二、后端模块

```text
backend/log-anomaly-detection/
├── pom.xml
└── src/
    ├── main/
    │   ├── java/com/hzk/loganomaly/
    │   │   ├── LogAnomalyDetectionApplication.java
    │   │   ├── common/            # Result、异常、工具类
    │   │   ├── config/            # Web、MyBatis-Plus、业务配置
    │   │   ├── controller/        # 登录、上传、日志、告警、检测
    │   │   ├── service/ + Impl/   # 业务接口与实现
    │   │   ├── mapper/            # MyBatis-Plus Mapper
    │   │   ├── entity/            # 数据库实体
    │   │   ├── dto/               # 查询条件 / 返回对象
    │   │   ├── vo/                # 登录返回对象
    │   │   ├── interceptor/       # JWT 拦截器
    │   │   └── rule/              # 规则引擎
    │   └── resources/
    │       ├── application.yml
    │       └── mapper/
    │           └── AccessLogMapper.xml
    └── test/java/
        ├── com/hzk/loganomalydetection/   # 上下文测试
        └── com/hzk/loganomaly/rule/       # 规则单元测试
```

详见 [03-后端设计](03-后端设计.md)。

## 三、Python 模块

```text
backend/detection-service/
├── clean_data.py                  # 数据清洗与采样
├── personas.py                    # 合成 IP 画像与行为
├── main.py                        # FastAPI Hello World 桩
├── test_main.http
├── ipdb/ip2region_v4.xdb
└── .venv/                         # 本地虚拟环境（gitignore）
```

没有 `requirements.txt`，也没有检测接口、特征工程、模型与数据库客户端。详见 [05-Python 数据生成与检测服务](05-Python数据生成与检测服务.md)。
