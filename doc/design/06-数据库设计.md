# 数据库设计（log_anomaly）

- 数据库：`log_anomaly`，字符集 `utf8mb4`，排序规则 `utf8mb4_general_ci`
- 所有表使用 `ENGINE=InnoDB`
- 建表脚本：[`sql/init.sql`](../../sql/init.sql)。脚本会先 `DROP TABLE` 再创建，重复执行会清空已有数据
- 初始化账号：`admin` / `123456`（密码以 BCrypt 密文存储）

## 表一览

| 表名          | 说明                                             | 对应实体               |
| ------------- | ------------------------------------------------ | ---------------------- |
| `user`        | 管理员账号                                       | `entity/User.java`     |
| `upload_task` | 上传任务记录与脏数据统计                         | `entity/UploadTask.java` |
| `access_log`  | 访问日志（核心表，含规则/模型/最终三层异常标记） | `entity/AccessLog.java` |
| `alert`       | 异常告警记录                                     | `entity/Alert.java`    |

## 表关系

- `access_log.upload_task_id` → `upload_task.id`：一条日志属于某次上传任务（逻辑关联，未建外键约束）
- `alert.ip` → `access_log.ip`：告警按 IP 关联到访问日志（逻辑关联，未建外键约束）

## 1. user — 用户表

存储登录账号，当前只有 `admin` 一个种子账号。

| 字段          | 类型         | 允许空 | 默认值              | 说明              |
| ------------- | ------------ | ------ | ------------------- | ----------------- |
| `id`          | BIGINT       | 否     | AUTO_INCREMENT      | 主键              |
| `username`    | VARCHAR(50)  | 否     | -                   | 用户名            |
| `password`    | VARCHAR(100) | 否     | -                   | 密码(BCrypt加密)  |
| `nickname`    | VARCHAR(50)  | 是     | NULL                | 昵称              |
| `role`        | VARCHAR(20)  | 是     | `'admin'`           | 角色              |
| `status`      | TINYINT      | 是     | `1`                 | 1启用, 0禁用      |
| `create_time` | DATETIME     | 是     | CURRENT_TIMESTAMP   | 创建时间          |

索引：

| 索引名        | 类型   | 字段       |
| ------------- | ------ | ---------- |
| `PRIMARY`     | 主键   | `id`       |
| `uk_username` | 唯一   | `username` |

## 2. upload_task — 上传任务表

每次 CSV 上传生成一条记录，用于跟踪异步导入进度和脏数据明细。

| 字段           | 类型         | 允许空 | 默认值            | 说明                     |
| -------------- | ------------ | ------ | ----------------- | ------------------------ |
| `id`           | BIGINT       | 否     | AUTO_INCREMENT    | 主键                     |
| `file_name`    | VARCHAR(255) | 否     | -                 | 文件名                   |
| `total_rows`   | INT          | 是     | `0`               | 总行数                   |
| `success_rows` | INT          | 是     | `0`               | 成功入库数               |
| `fail_rows`    | INT          | 是     | `0`               | 失败数                   |
| `fail_detail`  | TEXT         | 是     | NULL              | 失败原因(JSON 数组)      |
| `status`       | TINYINT      | 是     | `0`               | 0处理中, 1完成, 2失败    |
| `upload_time`  | DATETIME     | 是     | CURRENT_TIMESTAMP | 上传时间                 |
| `finish_time`  | DATETIME     | 是     | NULL              | 完成时间                 |

索引：

| 索引名    | 类型 | 字段 |
| --------- | ---- | ---- |
| `PRIMARY` | 主键 | `id` |

## 3. access_log — 访问日志表

核心业务表，一行对应一条访问日志。除基础访问信息外，还保存网络流特征和三层异常判定结果。

| 分组         | 字段             | 类型         | 允许空 | 默认值            | 说明                          |
| ------------ | ---------------- | ------------ | ------ | ----------------- | ----------------------------- |
| 基础信息     | `id`             | BIGINT       | 否     | AUTO_INCREMENT    | 主键                          |
| 基础信息     | `ip`             | VARCHAR(45)  | 否     | -                 | 访问 IP                       |
| 基础信息     | `ip_location`    | VARCHAR(100) | 是     | NULL              | IP 归属地                     |
| 基础信息     | `access_time`    | DATETIME     | 否     | -                 | 访问时间                      |
| 基础信息     | `url`            | VARCHAR(500) | 是     | NULL              | 请求 URL                      |
| 基础信息     | `status_code`    | INT          | 是     | NULL              | HTTP 状态码                   |
| 基础信息     | `method`         | VARCHAR(10)  | 是     | `'GET'`           | 请求方法                      |
| 基础信息     | `response_time`  | INT          | 是     | NULL              | 响应耗时(ms)                  |
| 基础信息     | `user_agent`     | VARCHAR(500) | 是     | NULL              | User-Agent                    |
| 网络流特征   | `dest_port`      | INT          | 是     | NULL              | 目标端口                      |
| 网络流特征   | `protocol`       | VARCHAR(20)  | 是     | NULL              | 协议(TCP/UDP/HTTP)            |
| 网络流特征   | `duration`       | BIGINT       | 是     | NULL              | 连接持续时间(微秒或毫秒)      |
| 网络流特征   | `src_bytes`      | BIGINT       | 是     | NULL              | 源端发送字节数                |
| 网络流特征   | `dst_bytes`      | BIGINT       | 是     | NULL              | 目标端发送字节数              |
| 异常检测标记 | `rule_abnormal`  | TINYINT      | 是     | `0`               | 规则判定: 0正常, 1异常        |
| 异常检测标记 | `rule_type`      | VARCHAR(100) | 是     | NULL              | 命中规则类型                  |
| 异常检测标记 | `model_score`    | DOUBLE       | 是     | NULL              | 模型异常分数                  |
| 异常检测标记 | `model_abnormal` | TINYINT      | 是     | `0`               | 模型判定: 0正常, 1异常        |
| 异常检测标记 | `final_abnormal` | TINYINT      | 是     | `0`               | 最终判定: 0正常, 1异常        |
| 关联信息     | `upload_task_id` | BIGINT       | 是     | NULL              | 所属上传任务                  |
| 关联信息     | `create_time`    | DATETIME     | 是     | CURRENT_TIMESTAMP | 创建时间                      |

索引：

| 索引名         | 类型 | 字段              | 用途                 |
| -------------- | ---- | ----------------- | -------------------- |
| `PRIMARY`      | 主键 | `id`              | -                    |
| `idx_ip`       | 普通 | `ip`              | 按 IP 查询/聚合      |
| `idx_time`     | 普通 | `access_time`     | 按时间范围查询       |
| `idx_abnormal` | 普通 | `final_abnormal`  | 筛选异常日志         |
| `idx_task`     | 普通 | `upload_task_id`  | 按上传任务查询       |

## 4. alert — 异常告警表

规则层与模型层结果合并后，按 IP 生成告警并跟踪处理状态。

| 字段            | 类型         | 允许空 | 默认值            | 说明                       |
| --------------- | ------------ | ------ | ----------------- | -------------------------- |
| `id`            | BIGINT       | 否     | AUTO_INCREMENT    | 主键                       |
| `ip`            | VARCHAR(45)  | 否     | -                 | 异常 IP                    |
| `alert_type`    | VARCHAR(50)  | 否     | -                 | 告警类型                   |
| `alert_source`  | VARCHAR(20)  | 否     | -                 | 来源: rule/model/both      |
| `description`   | VARCHAR(500) | 是     | NULL              | 告警描述                   |
| `trigger_time`  | DATETIME     | 否     | -                 | 触发时间                   |
| `status`        | TINYINT      | 是     | `0`               | 0未处理, 1已处理, 2误报    |
| `handle_time`   | DATETIME     | 是     | NULL              | 处理时间                   |
| `handle_remark` | VARCHAR(255) | 是     | NULL              | 处理备注                   |
| `create_time`   | DATETIME     | 是     | CURRENT_TIMESTAMP | 创建时间                   |

索引：

| 索引名      | 类型 | 字段           |
| ----------- | ---- | -------------- |
| `PRIMARY`   | 主键 | `id`           |
| `idx_ip`    | 普通 | `ip`           |
| `idx_status`| 普通 | `status`       |
| `idx_time`  | 普通 | `trigger_time` |
