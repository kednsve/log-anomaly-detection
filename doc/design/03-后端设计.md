# 03 - 后端设计

> 版本：2026-11-18

## 一、技术栈与启动

- Spring Boot 3.3.5 / Java 17 / Maven（无 wrapper）
- MyBatis-Plus 3.5.10.1（含分页插件）、MySQL
- EasyExcel 3.3.4 解析 CSV
- JJWT 0.13.0 登录认证，spring-security-crypto 提供 BCrypt
- Lombok、Jackson、fastjson2、JUnit 5

从 `backend/log-anomaly-detection/` 启动：

```
mvn spring-boot:run
```

先执行 `sql/init.sql`。`mvn test` 会启动 Spring 上下文，需要 MySQL 可用。

## 三、分层与约定

`controller` → `service` 接口 → `service.Impl` 实现 → MyBatis-Plus `BaseMapper` → Lombok 实体。没有自定义逻辑的服务直接继承 `ServiceImpl`，不重复写 CRUD。

- 查询条件统一用 `LambdaQueryWrapper`，每个条件用 `ChkNotNull.check(value)` 包裹，空值自动跳过；
- 分页统一使用 MyBatis-Plus `Page`，`PaginationInnerInterceptor` 将每页上限限制为 500；
- 复杂 SQL 放在 `resources/mapper/*.xml`，`map-underscore-to-camel-case` 已开启；
- 除登录外，接口参数通过 query/form 绑定，不使用 `@RequestBody`；更新使用 `updateById`，null 字段不会更新。

## 四、统一返回与异常

`Result` 固定包含 `code`、`msg`、`data`：

- 成功 `code = 200`；
- 业务错误通常 `code = 400`，也可携带自定义错误码（如 404、409）；
- `GlobalExceptionHandler` 统一处理 `BusinessException`、参数绑定异常和其他异常。

`BusinessException` 支持两种构造：

```java
new BusinessException("提示信息");          // code 为 null，按 400 返回
new BusinessException(409, "上传任务尚未完成"); // 携带自定义 code
```

JWT 拦截器拒绝请求时，HTTP 状态码为 401，响应体为 `{"code":403,"msg":"未登录或登录失效","data":null}`。

## 五、认证

- `POST /login`：请求体 `LoginDTO {username, password}`，校验成功后返回 `LoginVO {token, id, username, nickname, role}`；
- `PUT /login`：将 user 1 的密码重置为 `123456`（整个 `/login` 路径被拦截器排除，因此无需认证）；
- 密码使用 `BCryptPasswordEncoder` 校验，Bean 定义在 `BCryptPasswordEncoderConfig`；
- `JwtInterceptor` 拦截 `/**`，仅排除 `/login`；客户端需携带 `Authorization: Bearer <token>`；
- `JwtUtil` 对 `jwt.secret-key` 做 Base64 解码后作为 HMAC 密钥，因此该配置必须是合法 Base64；
- 拦截器校验通过后把用户 ID 放入 `UserContext`（ThreadLocal），请求结束时清理；
- CORS 在 `WebConfig` 中允许任意 origin pattern，并允许携带凭证。

## 六、CSV 上传与解析

### 6.1 上传流程

1. `POST /uploadTask/csv` 接收 multipart 字段 `file`（大小写不敏感地校验 `.csv`，上限 100 MB）；
2. 将文件保存到 `java.io.tmpdir/log_anomaly_temp/`，文件名加 UUID 前缀；
3. 同步创建 `upload_task`（`status=0`），返回任务 ID；
4. `@Async` 方法后台解析：CSV 解析在事务外完成，仅入库用短事务；
5. 成功写入 `status=1`、总行数、成功/失败行数、`fail_detail`、`finish_time`；失败写入 `status=2`；
6. 临时文件在 `finally` 中删除。

上传进度通过以下接口查询：

- `GET /uploadTask/polling?taskId=`：单个任务；
- `GET /uploadTask/query`：分页查询，条件见 `UploadTaskDTO`。

### 6.2 解析规则

`CsvUtil` 通过 EasyExcel 按列下标读取 13 列：

```
ip, ip_location, access_time, url, status_code, method,
response_time, user_agent, dest_port, protocol, duration, src_bytes, dst_bytes
```

- 仅接受 IPv4；URL 不能为空；状态码范围 100–599（无法解析时默认 200）；
- 时间支持 `yyyy-MM-dd HH:mm:ss`、`yyyy/MM/dd HH:mm:ss`、ISO `...Z`（含/不含微秒）、毫秒时间戳；
- URL/User-Agent 截断 500；归属地默认「未知」；方法默认 `GET` 并转大写；
- 非法行不会中断导入，错误信息以中文收集进 `upload_task.fail_detail`（JSON，上限 5000 字符）；
- 合法行初始化为 `rule_abnormal=0`、`model_abnormal=0`、`final_abnormal=0`、`rule_type='正常'`、`model_score=0.0`；
- 入库批量大小由 `my-config.access-log.batch-size` 控制（默认 2000）。

## 七、接口清单

| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| POST | `/login` | JSON `LoginDTO` | 登录，返回 token |
| PUT | `/login` | 无 | 重置 admin 密码为 `123456` |
| POST | `/uploadTask/csv` | multipart `file` | 上传 CSV，返回任务 ID |
| GET | `/uploadTask/polling` | `taskId` | 查询单个上传任务进度 |
| GET | `/uploadTask/query` | `UploadTaskDTO` | 分页查询上传任务 |
| GET | `/AccessLog/query` | `AccessLogDTO` | 分页查询访问日志 |
| PUT | `/AccessLog/update` | `AccessLog` 字段 | 更新日志（通常只传 id 和要改的列） |
| GET | `/Alert/query` | `AlertDTO` | 分页查询告警 |
| PUT | `/Alert/update` | `Alert` 字段 | 更新告警处理状态 |
| POST | `/Detect/run` | `taskId` | 对指定任务执行规则检测 |

除 `/login` 外均需要 `Authorization: Bearer <token>`。

### 7.1 访问日志查询条件

`AccessLogDTO`：`pageNum`、`pageSize`、`id`、`uploadTaskId`、`ip`（LIKE）、`statusCode`、`method`、`ipLocation`（LIKE）、`finalAbnormal`、`startTime`/`endTime`（作用于 `accessTime`，格式 `yyyy-MM-dd HH:mm:ss`）。

### 7.2 告警查询条件

`AlertDTO`：`id`、`taskId`、`ip`（LIKE）、`alertType`、`alertSource`、`description`（LIKE）、`status`、`startTriggerTime`/`endTriggerTime`、`startHandleTime`/`endHandleTime`。

## 八、规则引擎

规则检测入口为 `POST /Detect/run?taskId=`，主要类位于 `rule/` 包：

- `AccessLogMapper.selectIpFeatures` 一次性聚合出每个 IP 的总请求数、最后访问时间、404 数、401/403 数、分钟峰值；
- `RuleEngine` 遍历三条规则生成 `RuleHit` 列表；
- `RuleResultWriter` 在独立事务中重置标记、删除旧告警、按 IP 回写并插入新告警。

完整设计见 [04-规则引擎设计](04-规则引擎设计.md)。

## 十一、开发约定

- 注释、日志、面向用户的错误信息使用中文；
- `service` 实现类放在 `service.Impl`（大写 I）；
- 新增自定义配置统一放在 `my-config.*`，用 `@ConfigurationProperties` 绑定；
- 时间格式统一 `yyyy-MM-dd HH:mm:ss`，时区 `Asia/Shanghai`。
